📝 Note Application

A lightweight and responsive Note Application built using pure HTML, CSS, and JavaScript. This app allows users to quickly create, edit, and manage notes directly in the browser.

🚀 Features
✍️ Add, edit, and delete notes
💾 Data saved in browser (LocalStorage)
⚡ Fast and lightweight (no frameworks)
📱 Responsive design
🎨 Clean and simple UI
